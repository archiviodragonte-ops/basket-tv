# Basket TV — versione definitiva
La pagina crea i giorni dinamicamente e non si ferma al 4 ottobre. I dati sono in data.json e l'aggiornamento automatico è gestito da GitHub Actions.
Fonti principali configurate: LBA e LNP. Gli orari indicati dal workflow sono UTC: 08:00 e 21:00 UTC; vanno portati agli orari italiani desiderati se si vuole esattamente 10:00 e 23:00 locali tutto l'anno.
